About Album Browser

📖 Application

A single-page Angular application demonstrating routing, HTTP requests, and reactive data handling using the JSONPlaceholder public API.

👤 Author

Abenov Altair
Course: Web Development — Lab 6

🛠️ Technologies

  • Angular 17+ Standalone Components
  • Angular Router with route parameters
  • HttpClient with Observables
  • JSONPlaceholder REST API

⚙️ Features

  • 6 configured routes
  • Browse and search 100 albums
  • Photo gallery view per album
  • Edit and delete albums (simulated)
